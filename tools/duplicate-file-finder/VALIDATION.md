# 验证记录

Windows x64、Python 3.14.6、PyInstaller 6.21.0。

`test_duplicate_finder.py` 通过实际临时文件验证：不同名称的相同内容被分组，同名不同内容不会被误分组；中文及带空格路径、SHA-256、UTF-8 BOM CSV、大小过滤、空文件、硬链接去重、文件及目录链接跳过、取消、读取期间文件变动、防覆盖及扫描文件保持原样。

源码和独立 `DuplicateFinder.exe` 均通过命令行帮助、真实目录扫描、中文 CSV、报告防覆盖及负数范围检查。EXE 文件大小为 13,081,863 字节，未签名。

图形界面使用独立 EXE 实际操作验证：填写测试目录，点击“开始扫描”，正确显示 1 组、2 个文件，中文路径正常；点击“导出 CSV”并在系统保存对话框选择新报告路径，实际报告包含 2 行正确路径、18 字节和正确 SHA-256。

没有测试百万文件规模、所有网络盘或全部云盘客户端。检测到的链接及重解析点会跳过；容量为逻辑字节估算，不能当作实际磁盘可释放空间。界面预览最多 1000 个文件，CSV 保留全部结果。
