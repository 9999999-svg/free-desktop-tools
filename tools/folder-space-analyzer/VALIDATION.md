# 技术检查记录

2026-10-10，Windows x64。Python 3.14.6、3.11.9 分别执行 `python test_folder_space_analyzer.py`；PyInstaller 6.21.0 构建后执行 `python test_folder_space_analyzer.py --exe dist/FolderSpaceAnalyzer.exe`，通过。

实际目录检查包括：中文路径、递归子目录、空目录、零字节文件、根文件分组、大文件排序及数量、CSV/BOM/公式文本前缀、无效输入和防覆盖。五文件 52 字节统计准确；链接目录跳过且返回不完整，根链接拒绝，硬链接按路径计数后为六文件 57 字节。源码还检查取消、较小条目上限、写入 fsync 后取消及临时文件清理。

Windows `DirEntry.stat()` 的文件身份字段返回 0，最初导致子目录误判；以真实递归目录复现后改用 `Path.lstat()`，上述源码及冻结 EXE 测试重跑通过。

实际桌面 EXE 使用原生文件夹对话框选择中文目录，汇总为 5 文件、52 字节，资料子目录 40 字节；通过原生保存框导出 CSV，10 条数据记录、汇总/分组及公式前缀正确。源文件保留，未留下临时文件；截图只留本机。

范围：报告是逻辑字节数，不是实际磁盘占用或一致快照；未验证所有权限情形、网络/云存储、恶意本地并发攻击、其他 Windows 版本或病毒扫描。POSIX 发布路径未在本机执行。
