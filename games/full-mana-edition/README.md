# 精灵物语 · 无敌满蓝修改版

《精灵物语》的无敌满蓝修改版。最大蓝量为 **9,999,999**，每次蓝量变化后恢复满值，两个玩家角色共用修改。免费提供 Windows EXE 与 SWF，公开满蓝修改源码。

## 下载与使用

[下载 Windows EXE](https://github.com/9999999-svg/full-mana-edition/releases/download/v1.0.0/FullMana.exe) · [下载 SWF](https://github.com/9999999-svg/full-mana-edition/releases/download/v1.0.0/FullMana.swf) · [下载修改源码](https://github.com/9999999-svg/full-mana-edition/archive/refs/heads/main.zip)

下载 EXE 后双击运行，无需 Python 或系统 Flash 插件。SWF 适用于已有兼容播放器的用户。EXE 未签名，仅支持本项目提供的固定游戏版本。

## 修改源码

`patch_mana.py` 只使用 Python 标准库，无需 pip 依赖，可恢复对应原 SWF 或生成满蓝修改文件。命令行参数见 `python patch_mana.py --help`。
