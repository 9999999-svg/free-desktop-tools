# 验证范围

Python 3.11 标准库验证通过：

- 对应原 SWF 生成的满蓝 SWF 与现有满蓝文件逐字节一致。
- 复用现有播放器后生成的 EXE 与现有满蓝 EXE 逐字节一致。
- 反向恢复原 SWF 后再次应用补丁，结果完全一致；修改恰好 16 字节。
- 执行实际被替换的 AVM2 算术操作码：原版 1 级上限为 60、消费 20 后为 40；修改后验证 1 至 40 级、1120 次不同当前值及蓝量增减组合，结果始终为 9,999,999。
- 拒绝错误版本输入，不覆盖已有输出文件。

下载后可以自行验证：

```powershell
python verify.py FullMana.swf FullMana.exe
```
